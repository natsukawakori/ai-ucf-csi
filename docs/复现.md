# 复现指南

从零复现「CSI 反馈 → 预编码 → 频谱效率」的全部结果。命令均在仓库根目录执行。

## 0. 环境

```bash
python -m venv .venv && . .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

- Python 3.11，PyTorch（CPU 亦可，GPU 明显更快）
- 数据：DeepMIMO `O1_3p5` 场景包，解压或直接保留 zip 均可；适配脚本支持直接读 zip

## 1. 适配真实信道

```bash
python src/data/adapters/deepmimo_rays.py \
  --zip  deepmimo_scenarios/o1_3p5.zip \
  --out  data/deepmimo_o1_r18 \
  --ap-count 18 --ue-count 18 --candidates 6 --serving 3 \
  --users 8000 --train-snapshots 1200 --val-snapshots 200 --test-snapshots 200
```

产出 `H_*.npy`、`beta_*.npy`、候选/服务索引、`ue_positions`、`los` 与 `manifest.adapter.json`。
阵列合成公式见 [系统与口径.md](系统与口径.md) §1.2。

## 2. 派生数据与门禁

```bash
python src/data/dataset.py --config configs/cf_r18_deepmimo.yaml \
  --data-dir data/deepmimo_o1_r18 --build
```

构建归一化码字张量、功率标签与服务集；同时执行门禁 `K·S ≥ L`。

## 3. 评测链路自检（必做）

```bash
python evaluate.py --config configs/cf_r18_deepmimo.yaml \
  --data-dir data/deepmimo_o1_r18 --split test --max-snapshots 50 \
  --precoder mrt --interference-scope full --out runs/gate.json
```

通过标准：

- 恒等重构 NMSE < −140 dB；
- `perfect` 与 `recon` 的 SE 逐位相同；
- 干扰门禁：非空干扰链路比例 100%。

另可运行 6 个独立自检：

```bash
for t in tests/test_{csi_codec,generate_cf,precoding,precoding_rzf,power,interference_scope}.py; do
    python "$t" || echo "FAILED $t"
done
```

## 4. 训练四个骨干

```bash
python scripts/train_zoo.py --data-dir data/deepmimo_o1_r18 \
  --archs clnet,csinet,crnet,acrnet --dims 8,32 --seeds 0,1,2,3,4,5 \
  --epochs 200 --outdir runs/zoo
```

- 断点续训：已生成 `summary.json` 的运行会被跳过；
- 变体（宽度 / 填充方式 / warmup）会进入目录名，互不覆盖。

## 5. 评测矩阵与统计

```bash
python scripts/zoo_matrix.py --ckpt-root runs/zoo \
  --config configs/cf_r18_deepmimo.yaml --data-dir data/deepmimo_o1_r18 \
  --outdir runs/zoo-matrix --kappas 1,16

python scripts/zoo_stats.py --csv runs/zoo-matrix/matrix.csv
```

矩阵对每个检查点评 MRT / RZF(κ=1) / RZF(κ=16) 三种设置，并按种子做配对检验。

## 6. 附加实验

```bash
# 功率策略 × 预编码
python scripts/sweep_power.py --config configs/cf_r18_deepmimo.yaml \
  --data-dir data/deepmimo_o1_r18 --ckpt-root runs/zoo --arch csinet --d 32 \
  --seeds 0,1,2 --policies equal,gain,beta --kappas 1,16

# 潜码量化验证（8/6/4 bit）
python evaluate.py --config configs/cf_r18_deepmimo.yaml --data-dir data/deepmimo_o1_r18 \
  --latent-dim 32 --codec runs/zoo/zoo-csinet-d32-s0/codec.pth \
  --precoder mrt --latent-quant-bits 8 --out runs/q8.json
```

## 8. 诊断工具

| 脚本 | 用途 |
| --- | --- |
| `check_channel_conditions.py` | 覆盖率、遮挡、多径、几何、动态范围 —— 判断数据集是否像去蜂窝系统 |
| `probe_ratio.py` | 配比 (K, M, S) 探查（免训练，重算标签直接评 SE） |
| `stratify_los.py` | 按每用户 LOS AP 数分层（需合并三个 split） |
| `diagnose_nmse.py` | NMSE 三种口径与遮挡链路污染排查 |
| `audit_csi_results.py` | 结果矩阵完整性审计（重复行、缺失格、JSON 与 CSV 一致性） |
