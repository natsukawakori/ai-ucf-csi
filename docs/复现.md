# 运行方式

环境：Python 3.11、PyTorch、numpy、scipy、matplotlib。数据为 DeepMIMO `O1_3p5`，
从官网获取后放于 `deepmimo_scenarios/`。

## 数据准备

```bash
python src/data/adapters/deepmimo_rays.py \
  --zip deepmimo_scenarios/o1_3p5.zip --out data/deepmimo_o1_r18 \
  --ap-count 18 --ue-count 18 --candidates 6 --serving 3 \
  --users 8000 --train-snapshots 1200 --val-snapshots 200 --test-snapshots 200

python src/data/dataset.py --config configs/cf_r18_deepmimo.yaml \
  --data-dir data/deepmimo_o1_r18 --build
```

## 训练与评测

```bash
python scripts/train_zoo.py --data-dir data/deepmimo_o1_r18 \
  --archs clnet,csinet,crnet,acrnet --dims 8,32 --seeds 0,1,2,3,4,5

python scripts/zoo_matrix.py --ckpt-root runs --config configs/cf_r18_deepmimo.yaml \
  --data-dir data/deepmimo_o1_r18 --kappas 1,16

python scripts/zoo_stats.py --csv runs/zoo-matrix/matrix.csv
```

训练支持断点续训（已完成的运行会跳过），评测矩阵按配置续评。

## 出图

```bash
python scripts/fig_csi_feedback.py --csv runs/zoo-matrix/matrix.csv --outdir docs/figures
python scripts/fig_error_heatmap.py --data data/deepmimo_o1_r18 \
  --ckpt-root runs --arch csinet --seed 0 --out docs/figures/fig3-spatial-nmse.png
```

## 其他脚本

| 脚本 | 用途 |
| --- | --- |
| `check_channel_conditions.py` | 覆盖率、遮挡、多径、几何等信道条件检查 |
| `probe_ratio.py` | 候选数与服务数配比探查 |
| `stratify_los.py` | 按 LOS 比例分层统计 |
| `diagnose_nmse.py` | NMSE 口径与遮挡链路排查 |
| `sweep_power.py` | 功率策略与预编码组合扫描 |
| `audit_csi_results.py` | 结果矩阵完整性审计 |
