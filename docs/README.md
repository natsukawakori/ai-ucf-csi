## 阅读顺序

1. 先看仓库根目录的 README，了解问题、方法与本项目最重要的三条结论；
2. 需要判断数字是否可用，读 `系统与口径.md` 的「评测路径的三条不变量」与「不能宣称的边界」；
3. 需要复核具体数值，读 `结果与统计.md`；
4. 需要看分簇与波束的系统级对比，读 `系统级优化结果.md`；
5. 需要重跑，按 `复现.md` 执行。
